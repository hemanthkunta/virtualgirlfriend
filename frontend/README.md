# Virtual Girlfriend Frontend

A beautiful, glassmorphism-styled React-like vanilla frontend for the Virtual Girlfriend AI.

## How to use:
1. Ensure your backend is running: `python app.py` (which runs on port 5000).
2. Simply open `index.html` in any web browser! You do not need to install Node or npm.

## Features:
- **Beautiful Glassmorphism UI:** Animated glowing orbs, dark mode, and blurred panels.
- **Real-time Chat:** Type messages or use the microphone to talk.
- **Dynamic Video Responses:** It automatically plays the lip-synced video generated by the backend.

## Lip Sync Upgrade
The backend now supports using the high-quality **Fal.ai API** for lip-syncing instead of the blurry, slow local Wav2Lip. 
To enable this:
1. Get an API key from Fal.ai.
2. Add `FAL_KEY=your_key_here` to your `.env` file.
3. Install the client: `pip install fal-client`
4. The system will automatically use the high-quality API! If the key is missing, it falls back gracefully to a non-lip-synced version so your app never crashes.
